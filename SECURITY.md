# Security reporting

Do not publish vulnerabilities, tokens, authorization URLs, vault files, or
unmasked account screenshots in public issues.

Email security reports privately to [contact@formaggio.software](mailto:contact@formaggio.software).
Include the affected version, OS, architecture, impact, and sanitized reproduction
details. Do not include live credentials or account data.

GitHub Security → Report a vulnerability is an additional private channel when
enabled. For customer support and purchase questions, use the same email address.
